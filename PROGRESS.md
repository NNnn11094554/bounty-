# PROGRESS — Meowgul

Файл ведётся по правилу 7 из ТЗ: что готово, что делается, что дальше, известные проблемы.
В новой сессии сначала прочитайте его и продолжайте с текущей фазы.

## Решения
- Название игры: **Meowgul** (meow + mogul), валюта — **PAW** (монеты с отпечатком лапы).
- Монорепо на npm workspaces: `shared` (типы API, форматирование), `backend`, `frontend`.
- Старый проект Woof Kombat перенесён в `legacy/woof-kombat/` (без удаления).
- Деньги в БД — `Decimal(38,4)`; цены и награды конфигов — целые (`BigInt`).
- Миграции Prisma сведены в одну `init` перед первым деплоем (фаза 12). Дальше каждое изменение схемы — новая миграция.

Дальше — деплой по README («Деплой на Render»): нужны токен бота от @BotFather и Telegram ID админа.

### v2 — доработка игры
- Тап по коту больше не открывает меню ссылки: картинка ушла из тап-зоны, отдельный слой ловит касания.
- Друзья: ссылка через бота `?start=ref_<id>`, бот запоминает пригласившего до первого входа
  (`PendingReferral`); у друга — уровень и «в сети»; загрузка, пустой список, ошибка с повтором.
- Уровень игрока 1–50 по заработанному; 13 котов и 6 эффектов тапа с редкостями, покупка за монеты (уровень
  и цену проверяет сервер) и за Stars; экран «Коллекция», вкладка «Магазин» с разделами.
- Живой кот: дыхание, взгляд за пальцем, эмоции на серии тапов, случайные действия, сон, реакции на события.
- Airdrop: очки, место, готовность и требования; кошелёк TON скрыт флагом `TON_WALLET_ENABLED` (код и данные
  кошелька сохранены).

### v3 — новый персонаж
- Кот в полный рост и кнопка TAP вместо круга с котом: картинка вырезается из «шахматки» при сборке,
  хвост — отдельный слой (качается), веки — для моргания и сна, огоньки на наушниках и кроссовках.
- Тапать можно по кнопке и по коту; эмоции, серии тапов, сон и ввод шифра — как раньше.
- 13 скинов — перекраски нового кота и его кнопки (id, уровни и цены прежние, купленное сохраняется).
- Портрет нового кота — в иконках, аватарах лиг, экране загрузки, превью ссылки и приветствии бота.

### v5 — кот = кнопка игры
- Кнопки TAP больше нет: тапают по самому коту (весь силуэт), подсказка для нового игрока — один раз.
- Голова — отдельный слой (движется, смотрит в сторону, жмурится от тапа по голове); надпись с ремня убрана.
- Реакции на тап — пружинная физика без наложения анимаций: после 50 быстрых тапов кот в исходной позе.
- Спокойные движения в покое с разными периодами; спокойные действия с паузой между ними.
- Главная: энергия с полоской отдельной строкой, ниже Mine / Earn / Boost.

### Сайт игры (`/site/`)
- Промо-сайт — отдельная страница той же сборки (`frontend/site/index.html`, `frontend/src/site/`), игра не
  меняется. Одна 3D-сцена (three.js): камера летит по прокрутке через 6 станций — главная, игра (демо с тапами),
  коллекция котов (кольцо в глубине), прокачка, задания, Airdrop (без кошелька). Подробно — README, «Сайт игры».
- Коты сайта — 6 карточек высокого разрешения из `assets-src/skins/hires/`, собраны конвейером скинов
  (`build.mjs site` → `public/assets/site/cats/`).
- `RollingNumber` — стили рядом с компонентом (`RollingNumber.css`); чанки сборки по пакету: страница без
  framer-motion его не грузит.

## Известные проблемы
- В облачной среде разработки недоступны api.telegram.org и TON-сервисы: бот и TON Connect проверяются
  тестами с моками; вживую — после деплоя.
- Бесплатные планы Render засыпают (Web Service) и удаляются через 30 дней (PostgreSQL) — для игроков нужен
  платный план (см. README).
