# 🐈‍⬛ Meowgul — Telegram Mini App «тапалка + карточки»

Игрок вместе с чёрным котом растит свою криптокомпанию от подворотни до небоскрёба: тапает кота,
покупает карточки с пассивным доходом, поднимается по лигам, зовёт друзей. Валюта — монеты **PAW**
с отпечатком кошачьей лапы.

> [локальный запуск](#локальный-запуск) → [деплой на Render](#деплой-на-render) →
> [как добавить карточку](#карточки-mine) и [задание](#earn-ежедневная-награда-и-задания) →
> [как сменить баланс](#карточки-mine) → [админка](#админ-панель).

## Стек

- **frontend/** — React 18, Vite, TypeScript, Tailwind CSS, Zustand, Framer Motion
- **backend/** — Node.js 20, Fastify, TypeScript, Prisma, PostgreSQL, grammY (бот)
- **shared/** — общие типы API и форматирование чисел
- Тесты: Vitest (unit + интеграционные на тестовой БД), Playwright (e2e). CI — GitHub Actions.

## Персонаж

Картинка кота лежит в `frontend/public/assets/character.png` (PNG 1254×1254) и используется как есть:
круглая композиция с собственной белой обводкой показывается в круглой маске по центру, а цвет лиги меняет
только кольцо и свечение вокруг неё. Чтобы заменить персонажа, положите новый квадратный PNG на место этого
файла — все размеры пересоберутся при следующей сборке (`npm run assets -w frontend`).
При сборке скрипт `frontend/scripts/optimize-images.mjs` делает из неё WebP 512/1024, PNG-фолбэк,
иконки и OG-картинку в `frontend/public/assets/generated/`. Если файла нет — положите `character.png`
в эту папку; до тех пор используется заглушка-круг того же размера.

## Локальный запуск

Нужны Node.js 20+ и PostgreSQL 16 (проще всего через Docker).

```bash
npm install                    # зависимости всех пакетов
npm run db:up                  # PostgreSQL в Docker (или своя БД)
cp .env.example backend/.env   # при необходимости поправьте DATABASE_URL
npm run db:migrate             # миграции
npm run dev                    # API на :3000 и фронтенд на :5173
```

Откройте http://localhost:5173. Вне Telegram в development-режиме вход моковый: сервер выдаёт initData,
подписанный тестовым токеном (`GET /api/dev/init-data`, в production этого маршрута нет). Параметры игрока
задаются в адресе: `?uid=123&name=Мурка&premium=1&lang=en&ref=ref_456`.

## Авторизация

Клиент отправляет `Telegram.WebApp.initData` в заголовке `Authorization: tma <initData>`. Сервер проверяет
подпись HMAC-SHA256 токеном бота и свежесть `auth_date` (не старше 24 ч); без этого любой `/api/*` отвечает 401.
Дополнительно проверяются версия клиента (`X-Client-Version`, ответ 426) и режим техработ (503, админы проходят).

## Деплой на Render

В репозитории есть `render.yaml` (Blueprint): PostgreSQL `meowgul-db`, API `meowgul-api` (Web Service,
Node 20) и игра `meowgul-web` (Static Site).

**1. Бот в @BotFather**
- `/newbot` → имя и username бота (например, `meowgul_bot`). Сохраните токен — это `BOT_TOKEN`.
  Токен — секрет: только в переменных Render или в `backend/.env` (он в `.gitignore`), никогда в коде.
- Узнайте свой Telegram ID (например, у @userinfobot) — для `ADMIN_TELEGRAM_IDS`.

**2. Blueprint на Render**
- Render → **New → Blueprint** → выберите репозиторий; Render прочитает `render.yaml`.
- Заполните переменные, которые Render спросит (`sync: false`):

| Сервис | Переменная | Значение |
|---|---|---|
| meowgul-api | `BOT_TOKEN` | токен из BotFather |
| meowgul-api | `BOT_USERNAME` | username бота без `@` |
| meowgul-api | `WEBAPP_URL` | адрес игры, например `https://meowgul-web.onrender.com` |
| meowgul-api | `ADMIN_TELEGRAM_IDS` | ваш Telegram ID (несколько — через запятую) |
| meowgul-api | `CHANNEL_ID`, `CHANNEL_URL` | канал для задания «Подпишись»: `@channel` и `https://t.me/channel` (можно пусто) |
| meowgul-web | `VITE_API_URL` | адрес API, например `https://meowgul-api.onrender.com` |
| meowgul-web | `VITE_BOT_USERNAME` | username бота без `@` |

  Остальное задано в `render.yaml`: `DATABASE_URL` (из базы), `NODE_ENV=production`, `BOT_ENABLED=true`,
  `DAILY_RESET_UTC_HOUR=16`, случайный `WEBHOOK_SECRET`, `MINIAPP_SHORT_NAME=app`. `API_URL` задавать не нужно —
  на Render это адрес сервиса (`RENDER_EXTERNAL_URL`). Если имя сервиса занято и Render дал другой адрес,
  исправьте `WEBAPP_URL`/`VITE_API_URL` и нажмите **Manual Deploy**.
- Что происходит при деплое API: `npm ci` → сборка → `prisma migrate deploy` (одна миграция `init`) → старт.
  При старте сервер добавляет карточки и встроенные задания, ставит вебхук бота
  `API_URL/api/bot/webhook` с секретным заголовком, команды, описание и кнопку меню **Play**.
- Статика: сборка с `VITE_API_URL`; рядом с игрой создаётся `tonconnect-manifest.json` (адрес — из
  `RENDER_EXTERNAL_URL`, свой можно задать в `VITE_TONCONNECT_MANIFEST_URL`). Все пути переписываются
  на `index.html` (`/* → /index.html`), файлы сборки из `/build/*` кешируются навсегда.
- CORS: API принимает запросы только с `WEBAPP_URL` (дополнительные домены — `CORS_ORIGINS` через запятую).

**3. Mini App в @BotFather** (когда игра открылась по адресу `WEBAPP_URL`)
- `/newapp` → выберите бота → название, описание, картинка 640×360 → **Web App URL** = `WEBAPP_URL` →
  короткое имя `app` (= `MINIAPP_SHORT_NAME`). Ссылка на игру: `https://t.me/<бот>/app`, реферальные ссылки
  строятся от неё.
- Menu Button бот настраивает сам при запуске. Вручную: `/mybots` → бот → Bot Settings → Menu Button → URL.
- Для задания «Подпишись на канал» добавьте бота администратором канала.

**4. Проверка**
- `https://<api>/health` → `{"status":"ok"}`.
- Откройте бота → `/start` → **Играть**: вход проходит сам, офис открывается.
- `https://<игра>/admin` из Telegram под админским аккаунтом — админ-панель.

**5. Свой домен** — добавьте его в Render у `meowgul-web`, поменяйте `WEBAPP_URL` у API и URL Mini App в
BotFather (`/myapps` → Edit Web App URL).

> ⚠️ **Бесплатные планы Render — только для проверки.** Бесплатный Web Service засыпает через 15 минут
> без запросов: первый ответ приходит через ~50 секунд, бот в это время молчит, уведомления и рассылки не
> отправляются. Бесплатная база PostgreSQL удаляется через 30 дней. Для реальных игроков переключите
> `meowgul-api` на Starter или выше и базу — на платный план (с бэкапами).

## Карточки Mine

Экономика целиком в `backend/src/game/config/cards.ts`: 120 обычных карточек (по 30 в Markets, PR&Team,
Legal, Specials) и 15 лимитированных Specials. Формулы:

- цена уровня n — `round(baseCost × costMultiplier^(n−1))`, `costMultiplier` 1,7–2,2;
- прибыль за уровень n — `round(baseProfit × profitMultiplier^(n−1))`, `profitMultiplier` 1,05–1,2;
- `baseCost` и окупаемость первого уровня задаются **тиром** карточки (1–6) и множителем `k` внутри тира,
  `baseProfit = baseCost / окупаемость`. Окупаемость растёт с ~4–10 ч на первом уровне до 100+ ч к 10-му;
  дальше она резко растёт — поздние уровни работают как «мягкий потолок».
- Цена уровня не превышает 10^15: если карточка дорогая, её `maxLevel` уменьшается автоматически.

Прибыль в час игрока — сумма прибыли купленных уровней; пассивный доход начисляется сервером при каждом
запросе за время с прошлой синхронизации, но не больше 3 часов. Условия открытия (`card`, `friends`, `task`,
`league`) проверяются только перед первой покупкой. Кулдауны — от 10 минут до 24 часов после покупки уровня.

**Как добавить карточку:** допишите её в нужный массив в `cards.ts` (id, тир, иконка `рисунок/значок/палитра`
из `shared/src/cards.ts`, названия и описания RU/EN, условие, кулдаун), запустите `npm run balance-check` и
`npm test` — тесты проверят уникальность id и иконки, диапазоны множителей, окупаемость и ссылки условий.
После деплоя сервер сам добавит новую карточку в БД при старте. Новый рисунок — функция в
`frontend/src/components/cards/glyphs.tsx` (сетка 48×48) и имя в `CARD_GLYPHS`.

**Как сменить баланс игры:** все числа — в `backend/src/game/config/*.ts` (`game.ts` — тап, энергия,
пассивный доход; `boosts.ts`; `leagues.ts`; `cards.ts` — тиры `TIERS`). Карточки в работающей игре
хранятся в БД: после правки конфига выполните на сервере `node dist/seed.js --force` (или
`npm run db:seed -- --force` локально) — значения карточек перезапишутся из конфига. Уже купленные уровни
сохраняют прибыль, полученную при покупке.

**Лимитированные карточки:** если в админке у карточки не задано окно `availableFrom`–`availableUntil`, она
участвует в автоматической ротации (`LIMITED_ROTATION`: всегда 2 карточки в продаже по 72 часа, по кругу).
Купленная лимитированная карточка продолжает приносить доход и после окончания окна, но улучшать её нельзя
до следующего окна.

## Лиги и рейтинг

10 лиг по **всего заработанным** монетам (траты лигу не понижают): Bronze 0, Silver 5K, Gold 25K,
Platinum 100K, Diamond 1M, Epic 2M, Legendary 10M, Master 50M, Grandmaster 100M, Lord 1B — пороги и цвета
в `backend/src/game/config/leagues.ts`. Лига пересчитывается в единой функции изменения баланса, повышение
вызывает обработчики `onLeagueUp` (бонусы пригласившему — фаза 9).

`GET /api/leagues/:level/top` — топ-100 лиги, число игроков и место текущего игрока. Рейтинг собирается
SQL-запросом по индексу `(leagueLevel, totalEarned)` и кэшируется на минуту в памяти процесса; место игрока
вне топ-100 считается отдельным запросом и тоже кэшируется на минуту. Заблокированные игроки в рейтинг
не попадают.

## Earn: ежедневная награда и задания

**Ежедневная награда** — 10 дней подряд: 500, 1K, 2,5K, 5K, 15K, 25K, 100K, 500K, 1M, 5M
(`backend/src/game/config/rewards.ts`). Пропустил игровой день — серия начинается с Дня 1, после Дня 10
цикл начинается заново. Игровой день сбрасывается в `DAILY_RESET_UTC_HOUR` по UTC (16 = 19:00 по Киеву).
`POST /api/daily-reward/claim`; состояние приходит в `state.daily`.

**Задания** хранятся в таблице `Task`. При старте сервер создаёт встроенные (`backend/src/game/config/tasks.ts`):
«Подпишись на канал» (включается, когда заданы `CHANNEL_ID` и `CHANNEL_URL`; бот должен быть администратором
канала — подписка проверяется через Bot API `getChatMember`) и «Пригласи 3 друзей» (проверка по БД).
**Как добавить задание:** в админке, вкладка «Задания» (ссылки на соцсети, видео, спецпредложения,
подписка на другой канал), или через API админки:

| Метод | Что делает |
|---|---|
| `GET /api/admin/tasks` | все задания и сколько игроков их выполнили |
| `POST /api/admin/tasks` | создать: `id`, `type` (`TELEGRAM_CHANNEL`, `LINK`, `VIDEO`, `INVITE_FRIENDS`, `CHOOSE_HQ`, `CONNECT_WALLET`), `section` (`SPECIAL`, `LIST`, `AIRDROP`), названия и описания RU/EN, `icon`, `url` (только https), `channelId`, `requiredCount`, `reward`, `checkDelaySec` (по умолчанию 30), `sortOrder`, `isActive` |
| `PUT /api/admin/tasks/:id` | изменить |
| `DELETE /api/admin/tasks/:id` | удалить; если задание уже кто-то выполнил — только выключить |

Задания-ссылки (`LINK`, `VIDEO`) можно проверить через `checkDelaySec` секунд после перехода
(`POST /api/tasks/:id/start` → `POST /api/tasks/:id/check`). Награда начисляется один раз — параллельные
проверки и повторные запросы ничего не добавляют.

## Комбо дня и шифр

**Комбо дня** — 3 карточки, загаданные на игровой день. Если за день игрок улучшит все три — **+5 000 000**
(награды — `backend/src/game/config/rewards.ts`). Админ задаёт комбо на неделю вперёд
(`PUT /api/admin/combo/:dayKey { cardIds }`); если не задал — сервер при первом обращении выбирает случайно
по одной карточке из трёх разных категорий среди доступных (без лимиток, условий друзей/лиг/заданий и
не дороже 300K за первый уровень). На Mine угаданные карточки открываются в слотах, остальные — «?».

**Шифр дня** — слово из 4–7 латинских букв, вводится азбукой Морзе тапами по коту: короткое касание — точка,
нажатие дольше 0,3 с — тире, пауза 0,9 с — следующая буква. Награда **+1 000 000**. Слово не уходит на клиент:
игрок видит подсказку и число букв, проверку делает сервер (`POST /api/cipher/claim { word }`). Слова с
подсказками — `backend/src/game/config/ciphers.ts`; админ может задать своё (`PUT /api/admin/cipher/:dayKey`).
`GET /api/admin/daily` — комбо и шифры на 7 дней вперёд. `GET /api/combo` — комбо и шифр текущего дня для игрока.

## Друзья и рефералы

Реферальная ссылка игрока: `https://t.me/<BOT_USERNAME>/<MINIAPP_SHORT_NAME>?startapp=ref_<telegramId>`.
При **первом** входе с `start_param=ref_…` оба получают бонус: +5 000, а если у нового игрока Telegram
Premium — +25 000. Пригласить себя нельзя, уже зарегистрированный игрок по ссылке не засчитывается,
заблокированный пригласивший бонусов не получает. Когда друг достигает новой лиги, пригласивший получает
бонус за каждую пройденную лигу один раз (Silver +20K, Gold +30K, Platinum +40K, Diamond +60K, Epic +95K,
Legendary +195K, Master +400K, Grandmaster +800K, Lord +2M; за Premium-друга — вдвое больше).
Все суммы — `REFERRAL` в `backend/src/game/config/rewards.ts`.

`GET /api/friends?after=<id>` — ссылка, таблица бонусов, сколько всего получено и список друзей по 50.

## Airdrop и кошелёк TON

Вкладка Airdrop: задание «Подключи свой кошелёк TON» через TON Connect (`@tonconnect/ui-react`, грузится
только на этой вкладке) и задания раздела `AIRDROP` из админки. Владение кошельком подтверждается
**ton_proof**: сервер выдаёт подписанный payload на 15 минут (`GET /api/wallet/proof-payload`), кошелёк
подписывает адрес, домен игры, время и payload, сервер сверяет адрес с `stateInit`, берёт из него публичный
ключ (кошельки v3/v4/v5) и проверяет подпись ed25519 (`POST /api/wallet`). Домен должен совпадать с
`WEBAPP_URL`/`CORS_ORIGINS`, в production принимается только mainnet. Один кошелёк — один игрок.
`DELETE /api/wallet` — отключить. Манифест TON Connect отдаёт API: `GET /api/tonconnect-manifest.json`
(название, адрес и иконка игры из `WEBAPP_URL`); другой адрес манифеста можно задать в
`VITE_TONCONNECT_MANIFEST_URL`.

## Бот

Бот на grammY (`backend/src/bot/`) включается переменными `BOT_ENABLED=true` и `BOT_TOKEN`.
- `/start` — приветствие с космической картинкой (`assets/generated/welcome.jpg`, собирается вместе с игрой), кратким
  списком возможностей, кнопкой **Play** (Mini App) и кнопкой канала, если задан `CHANNEL_URL`.
  `/start ref_<telegramId>` открывает игру по реферальной ссылке (`?startapp=ref_…`).
  Тексты на русском и английском — по языку Telegram (`backend/src/bot/texts.ts`).
- При запуске бот сам ставит команды, описание «Что умеет этот бот?» (по-русски — и для украинского, белорусского
  и других языков из `RU_LANGS`) и кнопку меню **Play**. Повторно — только если тексты или адрес игры изменились.
- В production — вебхук `API_URL/api/bot/webhook`. Telegram передаёт секрет в заголовке
  `X-Telegram-Bot-Api-Secret-Token`: hex-значение, производное от `WEBHOOK_SECRET` (или от токена, если он не
  задан) — Telegram принимает в секрете только латиницу, цифры, `_` и `-`.
  В разработке — long polling. Если Telegram недоступен, бот повторяет попытку каждые 30 секунд, игра при
  этом работает.

## Уведомления

Уведомления отправляет очередь `Notification`, её обрабатывает воркер каждую секунду.
- Пишем только тем, кто разрешил: нажал `/start` или дал доступ в Mini App, и не выключил уведомления в
  настройках.
- Не больше 2 сообщений игроку за игровой день и не больше 25 сообщений в секунду. Сообщения старше 6 часов
  не отправляются.
- Если игрок заблокировал бота, уведомления ему выключаются. На ответ 429 очередь ставится на паузу.
- Поводы: энергия восстановилась (если игрок потратил её почти до нуля), вышло новое комбо дня (игрокам,
  которые заходили за последние 3 дня), по твоей ссылке пришёл друг.

## Онбординг и штаб-квартира

При первом входе — 3 слайда: тапай, карточки и пассивный доход, друзья. Затем выбор штаб-квартиры
котокомпании из 6 мест (`shared/src/hq.ts`). За выбор — **+5 000** один раз (встроенное задание
«Выбери штаб-квартиру»). Штаб-квартира видна в шапке Офиса. Онбординг можно пропустить. Сменить
штаб-квартиру можно потом, но награда повторно не начисляется (`POST /api/hq { hqId }`).

## Профиль, достижения и настройки

**Достижения** — 60 штук в пяти группах (прогресс, бизнес, друзья, каждый день, особые). Список, пороги и
награды — `shared/src/achievements.ts`: у каждого есть показатель (тапы, заработок, прибыль в час, лига,
карточки, друзья, серия ежедневки, комбо, шифры, задания, золотые монеты, дни в игре…) и порог.
Выдаёт только сервер (`backend/src/services/achievements.ts`):
- показатели из строки игрока проверяются после **каждого** изменения баланса;
- подсчитываемые (карточки, друзья, задания и т.д.) — в маршрутах, где они меняются, и все сразу при входе.
  Поэтому новое достижение, добавленное в конфиг, игроки получат при следующем входе.

Награда начисляется через общий журнал (`achievement_reward`). Если награда открывает следующее
достижение (например, поднимает лигу), оно выдаётся в том же запросе. Новые достижения приходят в
`state.achievements.fresh`: клиент показывает всплывающую плашку и отмечает их просмотренными
(`POST /api/achievements/seen`).

**Профиль** (`GET /api/profile`): статистика (тапы, заработано, дни в игре, лучшая серия, друзья,
карточки, комбо, шифры) и все достижения с датой получения или прогрессом.

**Настройки** (`PATCH /api/settings`): язык (авто/русский/английский), звук, вибрация, анимации
(полные/упрощённые), уведомления бота. Там же — смена штаб-квартиры и **удаление аккаунта**
(`POST /api/account/delete { confirm: true }`, кнопка активна через 3 секунды). Удаляется весь прогресс.
Telegram ID запоминается: если игрок снова зайдёт по чьей-то ссылке, бонусы за приглашение не начислятся
(защита от накрутки).

## Мини-события и подсказки

**Счастливый час** — целый час каждый тап приносит ×2 (энергия тратится как обычно). Время начала
одинаково для всех: через 2–21 час после сброса дня, кратно 15 минутам (зависит от даты). Админ может
назначить дополнительный счастливый час с другим множителем или выключить автоматический (настройка
`happyHour` в `AppSetting`). Множитель считает сервер (`POST /api/tap`), клиент показывает таймер в Офисе.
Бот объявляет начало игрокам, которые заходили за последние 3 дня (с учётом лимита 2 сообщения в день).

**Золотая монета** — иногда после пачки тапов сервер выпускает монету (не больше 3 в игровой день и
не чаще раза в 20 минут). Она пробегает над котом или под ним за 3 секунды — по лицу персонажа не
проходит. Поймать: `POST /api/events/:id/claim`. Принимается только своя монета, один раз и пока она
на экране (+1,5 с на сеть). «Поймал» быстрее 0,25 с после появления — не человек: попытка отклоняется,
`suspiciousScore` растёт. Награда — четверть прибыли в час, минимум 1 000. Выключается настройкой
`goldenCoin`. Параметры — `backend/src/game/config/events.ts`.

**Подсказки вкладок** — при первом открытии Офиса, Mine, Friends, Earn, Airdrop и Бустов затемнение
выделяет нужный элемент, рядом стрелка и текст, шаги листаются. Подсказки ждут, пока закроются онбординг,
модалки и сцены. Просмотр запоминается на сервере (`POST /api/tutorials/:id/seen`). Шаги —
`frontend/src/game/tutorials.ts`.

## Админ-панель

Адрес — `WEBAPP_URL/admin`. Пускает только Telegram ID из `ADMIN_TELEGRAM_IDS`: сервер проверяет это на
каждом запросе `/api/admin/*`, обычный игрок получит 403. Открыть можно из игры (Настройки → Админ-панель
видна только админам) или по прямой ссылке внутри Mini App. В разработке — `http://localhost:5173/admin?uid=<ваш ID>`.
Код админки — отдельный чанк (`frontend/src/admin/`), игрокам он не загружается. Интерфейс на русском и
английском.

- **Статистика** (`GET /api/admin/stats`): всего игроков, новые за день, DAU/WAU/MAU, удержание D1/D7/D30
  по когортам (по последнему полному дню), монеты на руках и заработанные, баны, подозрительные, очередь
  уведомлений, график активных и новых за 14 дней, топ рефереров.
- **Игроки**: поиск по id, Telegram ID, @username и имени. Список подозрительных (`suspiciousScore ≥ 3`).
  Карточка игрока с журналом операций (постранично), ручное начисление или списание с причиной (пишется
  в журнал как `admin_adjustment` с ID админа), бан с причиной, разбан (сбрасывает подозрительность).
- **Карточки**: правка всех полей, иконка из каталога рисунков (без своих картинок и логотипов), условия
  открытия, окна продажи лимитированных. Превью цены, прироста и окупаемости по уровням и проверка правил
  баланса — сервером, по тем же формулам, что в игре. Удалить можно только карточку без владельцев, иначе —
  снять с продажи. Новая прибыль действует для новых покупок уровней.
- **Задания**: создание, правка, удаление (выполненное игроками задание выключается).
- **Комбо и шифр** на 7 дней вперёд (ещё не выбранные выбираются при открытии).
- **Рассылки** через бота: текст, картинка, кнопка-ссылка; превью; тест себе; запуск, пауза, продолжение,
  отмена; прогресс обновляется сам. Получают игроки, разрешившие боту писать и не выключившие уведомления.
  Рассылка делит с уведомлениями лимит 25 сообщений в секунду, переживает перезапуск сервера (позиция
  хранится в БД), на 429 от Telegram ждёт, заблокировавшим бота больше не пишет.
- **Настройки**: технические работы с сообщением (админы заходят как обычно), минимальная версия клиента,
  счастливый час (автоматический и дополнительный с множителем ×2–×5), золотая монета.

## Проверка качества

| Что | Результат | Как проверить |
|---|---|---|
| Unit и интеграционные тесты | shared 10, backend 157 (на тестовой БД), frontend 9 — все зелёные | `npm test` |
| E2E (Playwright) | 46 сценариев, включая главный: вход → тап → покупка карточки → ежедневка → друг | `npm run test:e2e` |
| Покрытие игровой логики | 96 % строк в `src/game`, `src/auth`, `src/services` (порог в конфиге — 80 %) | `npm run test:coverage -w backend` |
| Lighthouse, мобильный режим | Performance 92–95, Accessibility 94, Best Practices 96; CLS 0 | `npx lighthouse <адрес игры>` |
| Бандл главного экрана | ≈ 157 KB gzip (код 59 + React 43 + Framer Motion 45 + CSS 10); Airdrop с TON Connect и админка грузятся отдельно | `npm run build -w frontend` |
| Линтер, типы, формат | без ошибок и предупреждений | `npm run check` |

**Защита от накрутки** проверена автотестами на каждый случай: двойной клик покупки, параллельные запросы,
подменённый и просроченный initData, отрицательные, дробные и огромные числа, повтор старой пачки тапов,
тапы скриптом быстрее 20 в секунду, слишком быстрая «ловля» золотой монеты, повторное приглашение после
удаления аккаунта.

**Экраны** проверяются на ширине 320, 375, 390 и 430 px (e2e `smoke`). Снимки всех экранов —
`SCREENSHOTS=<папка> npx playwright test screens` в `frontend/`. У игры своя тёмная «космическая» палитра,
шапку и фон Telegram она красит сама, поэтому в светлой и тёмной теме Telegram выглядит одинаково.

**Фон** — ночное небо с туманностью. Рисуется кодом (`frontend/src/lib/spaceSky.ts`, без картинок) порциями,
не мешая первым кадрам. Мерцающие звёзды, падающие звёзды и параллакс от наклона телефона — в
`SpaceBackground.tsx`; при «упрощённых анимациях» фон неподвижен.
