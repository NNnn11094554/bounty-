# 🐶 Woof Kombat — Telegram Mini App

Тапалка в стиле Hamster Kombat, только вместо хомяка — собачка, а вместо монет — косточки.

## Что есть

- **Тап по собачке**: косточки за тап, энергия с регенерацией, анимации, вибрация Telegram
- **10 уровней**: от «Щенка» до «Легенды»
- **Прокачка будки**: 18 карточек в 4 категориях, пассивный доход в час, офлайн-доход до 3 часов
- **Бусты**: полная энергия 6 раз в день, мультитап, запас энергии
- **Награда дня**: серия из 10 дней (500 → 5M)
- **Задания**: подписка на канал или чат, приглашение друзей, количество тапов
- **Друзья**: реферальная ссылка, +5 000 (или +25 000 с Premium) пригласившему и приглашённому
- **Сохранение**: локально и на сервере, данные подписываются Telegram (`initData` проверяется по HMAC)

## Структура

```
webapp/   — сам мини-апп (HTML/CSS/JS, без сборки)
server/   — бот (aiogram 3) + API + раздача webapp (aiohttp), SQLite
```

## Запуск

1. Создай бота в [@BotFather](https://t.me/BotFather) (`/newbot`) и получи токен.
2. Нужен публичный **https**-адрес. Для теста локально подойдёт `ngrok http 8080`.
3. Запусти:

```bash
pip install -r server/requirements.txt
export BOT_TOKEN=123456:ABC...
export WEBAPP_URL=https://xxxx.ngrok-free.app
python server/main.py
```

4. Напиши боту `/start` и нажми «🐶 Играть». Кнопка меню «Играть» ставится автоматически.

### Деплой (Render / Railway / любой VPS)

В репозитории есть `Dockerfile`. Создай сервис из репозитория и задай переменные окружения
`BOT_TOKEN`, `WEBAPP_URL` (адрес самого сервиса), при желании `CHANNEL_URL` и `CHAT_URL`.
Чтобы прогресс не терялся, подключи постоянный диск и укажи путь к базе в `DB_PATH`.

### Только фронтенд (без сервера)

Папку `webapp/` можно выложить на GitHub Pages, Vercel или Netlify и указать её адрес в BotFather.
Прогресс тогда хранится только в браузере, а друзья не считаются. Юзернейм бота задаётся в `webapp/config.js`.

## Настройка баланса

Всё в начале `webapp/app.js`: `LEVELS`, `CARDS` (цены и доход), `DAILY_REWARDS`, `TASKS`,
формулы `cardCost` и `cardProfitStep`.

## ⚠️ Важно перед реальным запуском

Сейчас игровая логика считается на клиенте, а сервер хранит присланное состояние. Для игры
с настоящими призами или аирдропом расчёт тапов, покупок и наград нужно перенести на сервер,
иначе баланс можно накрутить. Проверка подписки на канал тоже упрощена: награда выдаётся
после перехода по ссылке. Для честной проверки нужен `getChatMember` через бота.
